ZEHNASHEEN — FRAMER-STYLE ART PORTFOLIO V3

This version uses the three previously provided artworks and separates the site into:

1. HOME (index.html)
   - Spacious editorial homepage
   - Only 3 featured artworks
   - About, process, commissions and contact
   - Link to the full collection

2. ALL WORKS (gallery.html)
   - Dedicated gallery for your complete sketch collection
   - Filters: All / Portraits / Charcoal / Sketches
   - Large editorial cards, not a congested thumbnail wall
   - Click any artwork for a full-screen view
   - Easy to add many more artworks

ADDING A NEW SKETCH:
1. Put the image inside images/
2. Open gallery.html.
3. Copy one collection-card block.
4. Change:
   - data-image
   - data-title
   - data-category
   - image alt text
   - artwork number
5. Use categories such as:
   "portrait charcoal"
   "sketch"
   "portrait sketch"
   "commission charcoal"

The homepage should stay curated with your strongest 3–6 artworks. The gallery can contain your entire collection.

CONTACT:
Replace YOUR_NUMBER in the WhatsApp link with your full international number, without +, spaces or dashes.
Example: https://wa.me/91XXXXXXXXXX
Also replace the placeholder email and Instagram link.

Open index.html to start the website.
